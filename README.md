# Twitch System Theme

Расширение для браузера: тема Twitch автоматически переключается под тему
операционной системы. Тёмная тема системы — тёмный Twitch, светлая — светлый.

## Как это работает

Twitch хранит выбранную тему в `localStorage` под ключом `twilight.theme`:
`"1"` — тёмная, `"0"` — светлая. Если значения нет, Twitch берёт тему системы.
Как только пользователь один раз переключит тему вручную, значение
зафиксируется и перестанет следовать системе.

Тему в интерфейсе Twitch задают классы на элементе `<html>`:
`tw-root--theme-dark` и `tw-root--theme-light`. Twitch сам переключает их,
когда пользователь меняет тему.

Расширение делает три вещи:

1. Пишет в `twilight.theme` значение по теме системы до запуска скриптов Twitch
   (`document_start`), чтобы страница сразу открылась в нужной теме.
2. Ставит нужный класс на `<html>` и следит за темой системы через
   `prefers-color-scheme`.
3. Возвращает класс, если Twitch перерисует его при навигации внутри сайта.

Перезагрузка страницы не нужна: тема меняется сразу, как в системе.

## Установка (Chrome, Edge, Brave, Opera — движок Chromium)

1. Открой `chrome://extensions`.
2. Включи «Режим разработчика» (переключатель в правом верхнем углу).
3. Нажми «Загрузить распакованное расширение».
4. Выбери папку `twitch-system-theme`.
5. Открой `https://www.twitch.tv` — тема подстроится под систему.

## Установка (Firefox)

1. Открой `about:debugging#/runtime/this-firefox`.
2. Нажми «Load Temporary Add-on…».
3. Выбери файл `manifest.json` внутри папки.
4. Открой `https://www.twitch.tv`.

В Firefox расширение загружается временно (до перезапуска). Для постоянной
установки нужна подпись в Mozilla.

## Файлы

| Файл            | Назначение                                      |
|-----------------|-------------------------------------------------|
| `manifest.json` | Описание расширения (Manifest V3)               |
| `content.js`    | Записывает тему системы в `twilight.theme`      |

## Проверка

1. Смени тему системы (macOS: Пункт меню Apple → Системные настройки →
   Внешний вид).
2. Обнови открытую вкладку Twitch — интерфейс должен сменить тему.
3. На открытой вкладке смени тему системы — Twitch сменит тему сам, без
   перезагрузки.

## Ограничения

- Пока расширение включено, ручное переключение темы в меню Twitch сразу
  откатывается обратно на тему системы.
- Имена классов и ключ `twilight.theme` найдены в коде Twitch и не являются
  публичным API. Twitch может изменить их в любой момент.
