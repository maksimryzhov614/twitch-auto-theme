# Twitch System Theme

Расширение для браузера: тема Twitch автоматически переключается под тему
операционной системы. Тёмная тема системы — тёмный Twitch, светлая — светлый.
Перезагрузка страницы не нужна: тема меняется сразу, как в системе.

## Что нужно для установки

Ничего собирать и настраивать не нужно. В репозитории уже лежит всё
необходимое:

| Файл            | Назначение                                  |
|-----------------|---------------------------------------------|
| `manifest.json` | Описание расширения (Manifest V3)           |
| `content.js`    | Код: приводит тему Twitch к теме системы     |
| `README.md`     | Эта инструкция                              |

Нет зависимостей, нет сборки, нет иконок — только два рабочих файла. Браузеру
нужны именно они.

## Шаг 1. Скачай файлы

**Вариант А — без Git (проще).** На странице репозитория нажми зелёную кнопку
`Code` → `Download ZIP`. Распакуй архив в любое постоянное место, например в
`Документы`. Папка после распаковки должна называться
`twitch-system-theme-main` (или как назовёшь сам).

**Вариант Б — через Git.**

```bash
git clone https://github.com/maksimryzhov614/twitch-system-theme.git
```

Дальше важное: папку не удаляй и не переноси. Браузер загружает расширение
прямо из неё, и если папку убрать, расширение перестанет работать.

## Шаг 2. Установи в Chrome / Edge / Brave / Opera

Эти браузеры работают на движке Chromium, установка одинаковая.

1. Скопируй в адресную строку `chrome://extensions` и нажми Enter.
   В Edge адрес другой: `edge://extensions`.
2. В правом верхнем углу включи переключатель «Режим разработчика».
   Появятся три новые кнопки.
3. Нажми «Загрузить распакованное расширение».
4. В окне выбора открой папку, которую скачал на шаге 1, и нажми «Выбрать».
   Выбирать нужно саму папку с файлом `manifest.json`, а не отдельный файл.
5. На странице расширений появится карточка «Twitch System Theme» со
   статусом «Включено».

Если браузер пишет «Файл манифеста не найден» — значит выбрана папка уровнем
выше или ниже. Внутри выбранной папки должен лежать `manifest.json`.

## Шаг 3. Проверь

1. Открой `https://www.twitch.tv`.
2. Тема Twitch должна совпасть с темой системы.
3. Не закрывая вкладку, смени тему системы (macOS: меню Apple → Системные
   настройки → Внешний вид → «Светлый» или «Тёмный»). Twitch сменит тему сам,
   без перезагрузки.

## Установка в Firefox

1. Открой `about:debugging#/runtime/this-firefox`.
2. Нажми «Load Temporary Add-on…».
3. Выбери файл `manifest.json` внутри папки из шага 1.

В Firefox расширение живёт до перезапуска браузера. Чтобы оно сохранилось,
нужна подпись в Mozilla — без неё это ограничение Firefox, не расширения.

## Обновление после изменений кода

Если файлы обновились (например, после `git pull`):

1. Открой `chrome://extensions`.
2. На карточке «Twitch System Theme» нажми значок перезагрузки (круговая
   стрелка).
3. Обнови открытую вкладку Twitch (Cmd+R на macOS).

Переустанавливать расширение не нужно.

## Удаление

1. Открой `chrome://extensions`.
2. На карточке «Twitch System Theme» нажми «Удалить».

После удаления при следующей загрузке Twitch снова возьмёт тему из своей
настройки.

## Как это работает

Twitch хранит выбранную тему в `localStorage` под ключом `twilight.theme`:
`"1"` — тёмная, `"0"` — светлая. Если значения нет, Twitch берёт тему системы.
Как только пользователь один раз переключит тему вручную, значение
зафиксируется и перестанет следовать системе.

Тему в интерфейсе Twitch задают классы на элементе `<html>`:
`tw-root--theme-dark` и `tw-root--theme-light`. Twitch сам переключает их,
когда пользователь меняет тему.

Расширение делает три вещи:

1. Пишет в `twilight.theme` значение по теме системы до запуска скриптов Twitch
   (`document_start`), чтобы страница сразу открылась в нужной теме.
2. Ставит нужный класс на `<html>` и следит за темой системы через
   `prefers-color-scheme`.
3. Возвращает класс, если Twitch перерисует его при навигации внутри сайта.

## Ограничения

- Пока расширение включено, ручное переключение темы в меню Twitch сразу
  откатывается обратно на тему системы.
- Имена классов и ключ `twilight.theme` найдены в коде Twitch и не являются
  публичным API. Twitch может изменить их в любой момент — тогда расширение
  перестанет работать.
